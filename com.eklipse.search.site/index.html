Eklipse Search

A VS Code style search & replace view for Eclipse 2024-03 or newer. This is its update site, open it in Eclipse rather than in the browser:

https://eliakocher.github.io/eklipse-search/
  1. Help > Install New Software..., enter the URL above in Work with.
  2. Check Eklipse Search and uncheck Contact all update sites during install to find required software, otherwise Eclipse may also upgrade unrelated plugins.
  3. Finish the wizard. When asked, trust the signer Eklipse Search with the fingerprint bd16c7887e6a370ece3c202e4a232a6d4ce4a426, then restart.

To update, repeat these steps. Help > Check for Updates contacts all update sites, like leaving the box in step 2 checked. More in the README.
