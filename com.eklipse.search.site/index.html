Eklipse Search

A VS Code style search & replace view for Eclipse 2024-03 or newer. This is its update site, open it in Eclipse rather than in the browser:

https://eliakocher.github.io/eklipse-search/
  1. Help > Install New Software...
  2. Paste the URL above into Work with and press Enter.
  3. Check Eklipse Tools > Eklipse Search, Next, Finish, trust the unsigned content and restart.

Updates then come with Help > Check for Updates. More in the README.
